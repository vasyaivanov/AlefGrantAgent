# Alef investor one-pager

One US Letter page for investors, built 11 November 2026 from the CEO's brief.

- `alef-investor-one-pager.pdf` is the file to send.
- `alef-investor-one-pager.html` is the editable source. Fonts are embedded; photos and the logo are in `assets/`.
- `alef-investor-one-pager.png` is a preview render.
- `render.js` regenerates the PDF and PNG from the HTML (`node render.js`, needs Playwright).

`assets/alef-logo.svg` was traced from the small PNG logo so it prints sharp. Replace it with the official vector logo when one is available.
